Theory taught as note-name flashcards produces labels without sound. GAIA treats Basic Music Theory as how organized sound is predicted and shared — sixteen modules. Active making beats passive listening. Transfer to reading, math, and executive function is possible and not guaranteed.

## How GAIA drills a musical fact

Hear it. Name it. Write it. Place it (key, function, form). Make a two-bar answer that uses it. If AI wrote the bar: disclose. A learner who can label a V7 but not hear it is incomplete.
