Linguistics taught as grammar-police produces shame without science. GAIA treats Basic Linguistics as five competence layers scored apart — phonological, morphological, syntactic, semantic, pragmatic — plus diversity and computation. Sign languages are languages. Language vs dialect is political. UG and LLM-understanding stay open.

## How GAIA drills a linguistics claim

Name the layer. Name the evidence (contrast, corpus, brain, child, model). Separate description from prestige. Count languages as systems, not rankings. Forensic authorship as a court product: deny.
