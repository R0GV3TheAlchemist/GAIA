Anthropology taught as exotic-other lists produces spectacle without method. GAIA treats Basic Anthropology as four fields scored apart — cultural, biological, archaeological, linguistic — plus methods and a dated colonial record. Ancient DNA stays dated. Human remains stay under consent and repatriation rules.

## How GAIA drills an anthropology claim

Name the field. Name emic vs etic. Name the evidence (ethnography, bone, site, genome, text). Separate description from ranking. Relativism first, then the ethics tension. Extractive how-to: deny.
