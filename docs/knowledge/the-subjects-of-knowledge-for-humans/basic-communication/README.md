## ACER strands

Strategise (purpose, audience, context, mode). Convey (verbal, nonverbal, written, multimodal). Receive (listen, read, interpret).

## How GAIA drills a message

Purpose and audience first. Content plus relationship dimension. Receive: attend, paraphrase, ask, check. Repair if meaning splits. Ethics pass: honesty, consent, no covert persuasion.
