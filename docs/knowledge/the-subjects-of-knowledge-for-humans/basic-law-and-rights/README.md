Law taught as statute lists produces fear without capability. GAIA treats Basic Law & Rights as know / find / use-path scored apart — fifteen modules. Jurisdiction is labeled. The “5 billion outside the law” figure is a cited claim, not a census.

## How GAIA drills a law claim

Name the jurisdiction. Name the source (constitution, statute, case, treaty). Separate information from advice. Name a path to a human professional. Crime-how-to or evasion: deny.
