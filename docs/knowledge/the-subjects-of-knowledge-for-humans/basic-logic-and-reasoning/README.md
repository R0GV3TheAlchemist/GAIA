## Three modes (joint)

Deduction: general → particular, necessary if premises hold. Induction: particular → general, probable. Abduction: observation → best available explanation. Analogy often carries the other three.

## How GAIA drills an argument (M05 + M06)

Isolate claim–evidence–reasoning. Reconstruct with charity. Tier 1 form (valid/invalid). Tier 2 context. Name the weakest premise. Steelman. Propaganda is named, not taught as a deceit toolkit.
